# Citi Finance Virtual Job Simulation

## Project Overview

This repository documents my learning and practical work from a finance-focused virtual job simulation.

The project demonstrates my understanding of financial analysis, data interpretation, and structured problem-solving.

## Objectives

* Apply financial concepts to practical business scenarios.
* Analyze financial information and identify meaningful insights.
* Develop a structured approach to finance-related problems.
* Improve analytical and professional communication skills.

## Skills Demonstrated

* Financial Analysis
* Excel and Data Analysis
* Financial Reporting
* Business Problem-Solving
* Analytical Thinking

## Project Contents

* **Analysis:** My permitted analytical work and supporting spreadsheets.
* **Reports:** A summary of my findings and recommendations.
* **Screenshots:** Selected visuals illustrating my analysis, where sharing is permitted.

## Key Learnings

This project helped me understand how financial analysis can support business decisions and strengthened my interest in finance analytics, financial planning and analysis (FP&A), and financial control.
